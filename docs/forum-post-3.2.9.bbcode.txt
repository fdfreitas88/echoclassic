THREAD TITLE:
Echo Classic 3.2.9 — iOS 9 iPad Music skin, now with a Legacy theme

--------------------------------------------------------------------------------

[B]Echo Classic[/B] is a skin for Lyrion Music Server that looks like the iPad Music app from iOS 9, and that puts the [B]native sample rate and bit depth of what actually reaches the DAC[/B] in front of you. That is the reason it exists: on a hi-fi setup you want to know at a glance whether the 24/96 file you paid for is being served untouched or quietly resampled somewhere in the chain.

It is Vue 2 with no build step — the files the server ships are the files the browser runs — and it needs LMS 8.0 or later. Developed and verified against 9.1.1.

[B]Install:[/B] add this under [I]Settings → Plugins → Additional repositories[/I], then install Echo Classic from the list:

[CODE]https://raw.githubusercontent.com/fdfreitas88/echoclassic/main/repo.xml[/CODE]

Then pick [B]Echo Classic[/B] in [I]Server Settings → Interface[/I], or open [I]http://<server>:9000/echoclassic/[/I] directly.

Source, releases and changelog: [URL]https://github.com/fdfreitas88/echoclassic[/URL]

[SIZE="4"][B]What's new since 3.2.5[/B][/SIZE]

3.2.5 is the release most of you will have installed. Four published releases sit between it and 3.2.9 (3.2.6c, 3.2.7, 3.2.8, 3.2.9). Grouped by what actually changed for you rather than by version number:

[B]A third theme, and two more accents[/B]
[LIST]
[*][B]Legacy[/B] joins Light and Dark: bevelled chrome, grouped settings tables, embossed and engraved text, classic progress-bar defaults.
[*][B]Silver[/B] and [B]Black[/B] accents, bringing the total to seven. In Legacy, Silver keeps light chrome with dark bar text; Black carries dark chrome through the toolbar and mini player.
[*]Every theme/accent pair is contrast-checked — 155 pairs, all passing WCAG AA.
[/LIST]

[B]Settings, rebuilt[/B]
[LIST]
[*]Settings is one scrollable screen. The separate Theme, Colour Scheme, Fonts and four progress-bar subscreens are gone; Appearance is inline.
[*][B]Player layout is now one short screen.[/B] It used to be three repeated forms — Full player, Small player, Mini player — each with its own "Match app appearance" switch: 4 switches, 9 radio groups, 40 visible choices and 16 colour swatches, over 1,700 px of scrolling on a phone. It now opens on the only decision most people want — how the player opens and which side the panel takes — with one master appearance switch and everything else behind a single "Customize player appearance" disclosure that shows one surface at a time.
[*]The three player surfaces are named for where they appear: [B]Full player[/B], [B]Side panel[/B], [B]Bottom bar[/B]. Each can follow the app or carry its own theme, accent and font — and per-surface fonts actually change the typeface now; the feature had shipped inert.
[*]Crossfade became a switch with a duration beside it instead of a dropdown. Volume left Settings, because it belongs to the player.
[*][B]LMS server settings are skinned inside the interface[/B], including a plugin manager with status filters and counts. The server's own form stays authoritative; Echo Classic only dresses it. Back, Escape and tapping the active Settings tab all return properly instead of trapping you.
[/LIST]

[B]Navigation and search[/B]
[LIST]
[*][B]Search keeps its results.[/B] Searching for an artist, opening one and pressing Back used to drop you at the library root with the query erased. The term, the results and the scroll position now survive — on the on-screen Back and the browser's alike.
[*]Back pops the current tab's own stack instead of crossing into whichever tab you visited last.
[*]The My Music root picker is a proper keyboard listbox: arrows, Home/End, Escape, and focus returning to the button that opened it.
[/LIST]

[B]Playback and the queue[/B]
[LIST]
[*]A single-album queue no longer clips its group header or paints artwork over the rows beneath it, and the counter reads as a sentence again — "21 tracks · 2 h 4 min remaining".
[*]Playback recovers from the stopped remembered-track state that made Play look clickable while LMS had no usable queue. Empty-queue Next/Previous gives visible feedback instead of silently doing nothing.
[*][B]Losing the player is handled as one transition.[/B] The screen used to show "No player was found on LMS" next to a track name, with the progress bar running and the transport buttons enabled, and only a page reload settled it. Connection, track and controls now move together: the last known track stays visible, progress stops, and controls with nowhere to send a command are disabled.
[*]Undo is stamped with the player it belongs to, so it can never inject one player's queue into another.
[/LIST]

[B]Errors and language[/B]
[LIST]
[*]Service errors say something you can act on. Apps used to print [I][network] qobuz items 0 200 menu:qobuz: Failed to fetch[/I] straight to the screen; the protocol string now stays in the console and the screen says what happened and what to try.
[*]A malformed favourite shows an explicit failure with Retry instead of a dead row.
[*][B]English sessions are actually English.[/B] Portuguese labels had leaked into the action sheet, the player, album metadata, favourites, the selection bar and search. The source language is English and translations live in one file; the gate meant to enforce that was itself missing the words that leaked, and has been fixed.
[*]Language is picked in the skin's own Settings and outranks the LMS session language, so a server running in one language can still show the skin in another.
[/LIST]

[B]Layout[/B]
[LIST]
[*]The connection banner no longer covers the list toolbar. On a phone it used to sit on top of Filter, Sort and Select — tapping one hit the alert instead.
[*]Six layouts stopped reserving fixed pixel widths for siblings free to outgrow them, including a 330 px reserve sized for the English words "Playback queue" that was wrong in both directions once the label was translated.
[*]Momentum scrolling with contained overscroll across every scrollable region.
[/LIST]

[HR][/HR]

[SIZE="4"][B]Known limits, stated plainly[/B][/SIZE]

[LIST]
[*][B]Podium Sans and Espy Sans fall back[/B] to Geneva/Verdana. Both are offered in Settings, but the font files are not bundled — that waits on a licence decision. Chicago renders only where the system provides it.
[*][B]Portuguese is the only translation[/B] shipping today. The dictionary is keyed by the English phrase, so adding a language is an edit to one file, not a code change. Offers welcome.
[*][B]3.2.9 is freshly deployed.[/B] The screens above are the running build, but this release has had a first pass rather than a long soak. If something looks wrong, it probably is — please say so.
[*]The retired [I]/mojo[/I] alias is deliberately not registered and returns 404.
[/LIST]
