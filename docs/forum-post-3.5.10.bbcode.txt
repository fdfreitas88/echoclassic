[b]Echo Classic 3.5.10 is now available[/b]

Echo Classic 3.5.10 makes the Equalizer clearer on desktop and phones and fixes Qobuz menus that appeared to do nothing when tapped.

[b]What's New[/b]

The Equalizer's frequency-response graph has larger labels. Quick presets have clearer names and show which one is selected. Switching between Apple Squeezer and SqueezeDSP now shows progress and prevents conflicting input until the switch completes.

[img]https://raw.githubusercontent.com/fdfreitas88/echoclassic/main/images/release-3.5.10-equalizer-desktop.png[/img]

On phones, expand the response graph and swipe horizontally to inspect the full frequency range. Edited Equalizer settings now offer Apply and Discard together, and Echo Classic warns before leaving with unapplied changes, including when using browser Back.

[img]https://raw.githubusercontent.com/fdfreitas88/echoclassic/main/images/release-3.5.10-equalizer-phone.png[/img]

[b]Fixes[/b]

Qobuz menu rows that provide both an Open action and a shared Add action now open their submenu. This was verified in Chrome through My Favourites, Releases and an album's track list. Android 16 Chrome and Firefox still need device confirmation.

[b]Compatibility[/b]

Echo Classic 3.5.10 supports Lyrion Music Server 8.0 and later. SqueezeDSP and Apple Squeezer remain optional; ordinary playback and navigation continue without them.

[b]Installation / Upgrade[/b]

Add the Echo Classic repository URL under Server Settings > Plugins > Additional repositories, then install or update Echo Classic and restart LMS when requested:
